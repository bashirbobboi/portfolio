# bashir.is-a.dev

My personal website. It's where I keep my experience, projects and education in one place.

**Live:** [bashir.is-a.dev](https://bashir.is-a.dev)

## What's on it

- Where I've worked and what I did there
- Projects I've built, each with a short write-up, demo video and the tech used
- My education and certifications
- My GitHub activity

## How I built it

I built it with Next.js 16 (App Router), React 19 and Tailwind CSS v4, and it's deployed on Vercel.

Some parts I enjoyed building:

- **Radial navigation menu.** You can drag it around the screen, and it works on mobile too.
- **Animated tech stack grids.** Each project shows the tools I used, with tooltips.
- **Lazy-loaded project videos.** Videos only load when you scroll to them, so the page stays fast on mobile.

The UI uses shadcn/ui components, and the animations use Motion.

## Running it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
